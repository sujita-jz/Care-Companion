# Care Companion - Knowledge-Base Source Register

**Purpose:** This register records the public-health sources used to create the original, concise RAG fact sheets in this folder. The fact sheets are summaries for general information and must be clinically reviewed before a real patient-facing deployment.

**Important:** The project does not redistribute full third-party source documents here. Follow each organisation's terms, attribution rules, and update notices before downloading, storing, or republishing original PDFs.
